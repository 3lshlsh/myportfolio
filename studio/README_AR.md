# تشغيل لوحة أعمال علي

اللوحة في هذه الحزمة محلية. يلزم ربطها بمشروع تملكه على Sanity حتى تحفظ التعديلات. استخدم Node.js 22.12 أو أحدث. نفّذ أوامر اللوحة من مجلد studio.

## الربط الأول

1. المشروع المربوط هو ALI ABUWARDEH، ومعرّفه f61knmhk ومجموعة البيانات production.
2. على macOS يمكنك تشغيل Start-Studio.command من جذر الحزمة. يتطلب Node.js 22.12 أو أحدث ويفتح تسجيل الدخول الرسمي، ثم يشغّل اللوحة. استيراد المحتوى خطوة منفصلة موضحة أدناه. ويمكن تنفيذ الأوامر التالية يدوياً بدلاً منه.
3. ثبّت الاعتمادات وسجّل الدخول بحسابك من جهازك.

   ```sh
   npm ci
   npx sanity login
   ```
4. راجع رقم الهاتف وروابط التواصل وأهلية نشر الأعمال الواردة في portfolio.ndjson. الاستيراد التالي ينشئ سجلات منشورة في مجموعة عامة؛ الإخفاء داخل موقع الأعمال يؤثر في العرض فقط. بعد التأكد من المشروع والوجهة استورد البيانات. الخيار missing يحافظ على السجلات الموجودة عند تكرار الاستيراد.

   ```sh
   npx sanity dataset import portfolio.ndjson production --missing
   npm run dev
   ```

5. افتح عنوان اللوحة الذي يظهر في الطرفية وسجّل الدخول. إذا طلبت Sanity السماح بأصل الاستوديو المحلي، أضف عنوانه المحدد مع السماح بالاعتمادات في إعدادات CORS للمشروع.

## إدارة الأعمال

اختر القسم ثم علامة الإضافة لإنشاء سجل. لكل نص حقلا عربية وإنجليزية. الرقم الأصغر في ترتيب العرض يظهر أولاً. احفظ تعديلاتك بالنشر من زر Publish. الإخفاء قابل للتراجع من المفتاح داخل السجل. للحذف استخدم قائمة إجراءات المستند. جرّب الحذف أولاً على سجل تجريبي. تحتفظ الصور القديمة بمعرّفات محلية، ويمكن رفع صورة معتمدة في الموضع نفسه؛ تتقدم الصورة المرفوعة على المعاينة القديمة. يمكن سحب صور المعرض لتغيير ترتيبها.

تحرير نصوص الصفحة والأزرار يتم من قسمها بحسب الموضع. حافظ على مفاتيحها عند التحرير. تدعم العناوين فواصل الأسطر ووسوم التأكيد المستخدمة في V11. غيّر الشعار وروابط المنصات ورقم واتساب من «الهوية وروابط التواصل». حافظ على تبعيات التصميم بترك تنسيق المشاهد كما هو.

لقسم الفيديو أضف الغلاف وملفاً مناسباً للويب. لقسم المجسمات ارفع ملف GLB ذاتي الاحتواء أو STL؛ يظهر محدّد النماذج عند توفر نموذج منشور. بقي المجسم التجريبي ورفع الملفات محلياً ضمن التصميم السابق.

## بناء الموقع بمحتوى حسابك

من جذر المشروع، اضبط معرّف المشروع ومجموعة البيانات لأمر البناء. يقرأ البناء الوثائق المنشورة، ويعرض العناصر المرئية حسب الترتيب. يتوقف عند فشل القراءة أو نقص مفاتيح نصوص الواجهة.

```sh
npm ci
SANITY_PROJECT_ID=f61knmhk SANITY_DATASET=production npm run build
npm run preview
```

تشغيل npm run dev من الجذر مع المتغيرين نفسيهما يجلب نسخة البيانات عند بدء التشغيل. تشغيله دون معرّف يستعمل بيانات V11 المحلية. إعادة البناء يدوياً هي آلية هذه المرحلة؛ المعاينة المحمية وربط النشر التلقائي بـCloudflare مرحلتان لاحقتان.

## التحقق من الترحيل

تحتوي حزمة الاستيراد الأول على 44 مستنداً: 16 مشروعاً، 8 مراحل، 5 عبوات، 5 أفلام، 9 مجموعات نصوص، ومستند الإعدادات. لا يوجد نموذج أصلي في الحزمة الأولية. لإنشاء ملف الاستيراد من مرجع V11 شغّل npm run seed داخل studio. بعد الاستيراد افحص عدد كل نوع، وعدّل وصفاً واحداً بالعربية وتحقق من ثبات الإنجليزية. احتفظ بالحزمة الأصلية مرجعاً؛ لا تعد استيرادها لحفظ تعديلاتك.
